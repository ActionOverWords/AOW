WHAT THIS IS
  Every file the website needs to carry the Ring logo and the brand pack, at the paths the
  repository uses. The changed pages were edited one change at a time against the newest live
  copies: the repository as it stood at commit f885d4c, 2026-10-19 7:33 pm, which is the upload
  that added the score-over-time chart. No page was rewritten and no old copy was pasted over a
  newer one. Both of the evening's features are still in place in the copies here: the weekly
  email (aow-index.html, privacy-policy.html, tools/build-pages.js) and the score-over-time chart
  (aow-index.html), checked line by line.

  THIS IS THE THIRD AND CURRENT PACKAGE. Delete the two sent earlier the same evening: each was
  built before one of those features went live, and uploading one would undo it.

  IF YOU SHIP ANYTHING ELSE BEFORE UPLOADING THIS, SAY SO AND IT WILL BE REBUILT. aow-index.html
  is the file that keeps moving; the rest of the package is not affected by that kind of change.

HOW TO UPLOAD IT
  1. Copy this whole folder into Desktop\AOW-main\updates\ .
  2. Upload everything inside it through GitHub the way you do every update. The folders in here
     mirror the repository, so each file lands beside the one it replaces.
  3. Upload it all in one go. The pages point at the new brand files, so a half-upload would leave
     a page asking for a file that is not there yet.
  4. After the upload, open the Actions tab and watch "Build static pages". Pushing
     tools/build-pages.js starts it by itself; it rebuilds the 35 generated pages with the new logo
     and commits them a few minutes later. If it has not started after five minutes, run it by hand
     (Actions > Build static pages > Run workflow).

AFTER IT IS LIVE

  - Install the site once from Chrome's menu to check the app icon and name.
